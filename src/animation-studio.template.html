    Connect your LLM

    Run the local server in the repository. Keep its preview page open while you prompt your LLM.

    npm install
npm run build
npm run asset:studio

    For image capture, install the preview browser once:

    npx playwright install chromium

    Open http://127.0.0.1:4173/. Add this server to an MCP client. Replace the path with your repository path.

    { "mcpServers": {
  "animation": {
    "command": "node",
    "args": ["/absolute/path/my-3d2dge/tools/animation-mcp.mjs"]
  }
}}

    Try: “Read the current scene. Make the benches wider, change their wood to a dark color, and show me the result.” Or: “Make the wave slower and raise the hand. Show me a frame strip.”

    A coding agent can also edit .animation-studio/project.json. Each valid save updates the preview. Animation and scene assets share one project and undo history. Your MCP client runs the LLM; this editor shows its accepted edits.

    A hosted or downloaded page works as a local editor. Live file updates and MCP tools need the local server.
