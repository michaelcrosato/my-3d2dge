SOURCE: Resident Evil, a wing of the mansion
GAME ENGINE: my-3D2dge, the handoff package in this directory (start with README.md)

Make a game: an adaptation of the source on this engine, a complete vertical slice that plays from a title screen to an
end: a wing of a mansion, room by room under fixed cameras, a pistol to aim and few bullets, zombies that grab, a key
and a puzzle that open the way, herbs to mix, an item box and a typewriter to save at, and something waiting at the
end. Put it in game/: game/index.html plays it, game/game.js holds it, game/test.mjs tests it without a browser. Check
it with node tools/check.mjs game/index.html before you finish.
